# Semantic Firewall

Semantic Firewall — система обнаружения межсервисных поведенческих регрессий с помощью LLM. Рассматриваются изменения кода, которые сохраняют API-схемы, но нарушают предположения сервисов-потребителей.

Планируемый прототип будет анализировать Git diff, зависимости сервисов и код потребителей. Результат — структурированная оценка риска с указанием затронутых сервисов и подтверждающих участков кода.

Основная гипотеза: учёт межсервисных зависимостей повышает качество обнаружения регрессий по сравнению с анализом только diff. Проверка планируется на воспроизводимом наборе сценариев для микросервисов на Python; метрики — precision, recall, задержка и стоимость inference.

Статус: проектирование, реализация пока отсутствует.
