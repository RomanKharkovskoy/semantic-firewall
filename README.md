# Semantic Firewall

**Semantic Firewall** - система обнаружения семантических нарушений совместимости между микросервисами на основе LLM и машинного обучения.

Проект разрабатывается в рамках курса **ML System Design**.

## Проблема

Изменения в одном микросервисе могут нарушить работу других, даже если API остаётся структурно совместимым.

Например, сервис расчёта стоимости начинает возвращать цену с учётом налога вместо цены без налога. Другой сервис, использующий этот API, продолжает добавлять налог самостоятельно.

При этом структура ответа, названия полей и типы данных не меняются. Обычные проверки API-контрактов могут не обнаружить такое нарушение.

## Подход к решению

Semantic Firewall анализирует изменения исходного кода и их потенциальное влияние на зависимые сервисы.

Предполагаемый процесс анализа:

1. Получение Git diff и определение изменённых компонентов.
2. Анализ межсервисных зависимостей и извлечение релевантного кода.
3. Использование LLM для выявления изменений в поведенческих контрактах.
4. Оценка риска нарушения совместимости с помощью ML-модели.

Результат работы системы - оценка риска breaking change, список потенциально затронутых сервисов и объяснение обнаруженной проблемы.

## Цель проекта

Исследовать, насколько использование LLM и информации о межсервисных зависимостях повышает качество обнаружения семантических breaking changes по сравнению с базовыми методами анализа изменений кода.

Для разработки и оценки решения планируется создать воспроизводимый датасет на основе тестовой микросервисной системы с искусственно внесёнными изменениями.

## Статус

Проект находится на этапе проектирования. Архитектура и выбранные подходы могут измениться по результатам экспериментов.
